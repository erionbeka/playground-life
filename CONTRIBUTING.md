3. The contribution contains **no third-party material** (including code

Do not submit anything you cannot assign.

This repository is confidential. Do not share it, its contents, or

## Process

- Contact the maintainer before starting significant work.
- Keep changes scoped and follow existing conventions in the code and docs.
- Never commit secrets, credentials, or personal data.
- Add the standard source header to new files (see `scripts/license-headers.mjs`).
- By opening a pull request, you confirm you have read and accept these terms.
