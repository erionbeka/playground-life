# Android build runbook

Playground Life ships as a Capacitor 8 Android app. The web bundle in `dist/` is copied into the Android project by `npx cap sync android`.

## Prerequisites

- Node 20+ and npm
- JDK 21 (Capacitor's Android library targets source release 21)
- Android SDK with platform 36 and build-tools (set `ANDROID_HOME`)
- At least one device/emulator for smoke testing

## Environment

For an Android build the API is reached over the network, not same-origin. Set `VITE_API_URL` to the clinic API base URL before building:

```bash
# .env
VITE_API_URL=https://clinic.example.com
```

Leave empty for web builds (Vite dev proxy / nginx handle `/api`).

## Build commands

```bash
# Web bundle + sync into Android project
npm run build:android

# Debug APK
cd android
./gradlew assembleDebug
# -> android/app/build/outputs/apk/debug/app-debug.apk

# Release APK (requires a signing keystore configured in android/app/build.gradle)
./gradlew assembleRelease
```

## Full one-shot (web + sync + APK)

```bash
npm run build:android
cd android && ./gradlew assembleDebug
```

## Notes

- `android/app/src/main/assets/public/` is generated output; never edit it by hand. It is regenerated by `npx cap sync android`.
- The API must allow the Capacitor origin (or the device's origin) in `CORS_ORIGIN` and issue cookies with `Secure` + `SameSite=None` when served over HTTPS.
- Offline: the app refuses to pretend saves succeeded when the API is unreachable. Game results should be retried by the user.

## Release signing

Create a keystore once:

```bash
keytool -genkeypair -v -keystore playground-life.jks -keyalg RSA -keysize 2048 -validity 10000 -alias playground-life
```

Then build with properties (gradle.properties or `-P`):

```bash
./gradlew assembleRelease -PRELEASE_STORE_FILE=/path/playground-life.jks -PRELEASE_STORE_PASSWORD=... -PRELEASE_KEY_ALIAS=playground-life -PRELEASE_KEY_PASSWORD=...
```
